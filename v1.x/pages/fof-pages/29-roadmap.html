Mobile interface stabilization

High Priority

Finish the current phone-focused fixes without modifying Flarum core.

  • Notifications, Flags, and Drafts controls and actions.
  • Mobile dropdown/bottom-sheet clipping and navigation behavior.
  • Discussion list layout and composer/header overlap.

FoF Pages platform

High Priority

Continue turning FoF Pages into a consistent HCF page system with shared loading, error handling, responsive styling, and ID + slug routing.

Assets page improvements

In Progress

Improve the Assets page so real forum assets appear as useful cards and previews while keeping mobile behavior lightweight.
