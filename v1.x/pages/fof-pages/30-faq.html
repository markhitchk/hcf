Forum Website FAQ

Website: These answers apply to the browser version of Harley's Clan Forum.
What is Harley's Clan Forum?

Harley's Clan Forum is the community forum for discussions, announcements, support, Direct Messages, and Harley's Clan community activity.

What is the official forum address?

The primary forum address is forum.harleytg.com. The FreeFlarum address may be used as a fallback. See Domain Help for the currently supported addresses.

Do I need an account to use the forum?

Some public content can be viewed while signed out, but posting, replying, Direct Messages, notifications, profile features, and other account tools require you to sign in.

Are usernames and passwords case-sensitive?

Usernames are not case-sensitive. Passwords are case-sensitive, so capitalization must match the password you created.

How do I start a discussion?

Sign in, select the option to start a discussion, choose the correct tag or category when required, enter a clear title and message, then post it.

How do Direct Messages work?

Direct Messages let signed-in users have private forum conversations where the feature is available. If the Direct Messages interface is not loading correctly, reopen the page, sign in again, or contact support.

Why am I not receiving forum notifications?

Check your forum notification preferences and your browser notification permission. Browser or operating-system power-saving settings can also delay notifications.

Why does a forum page show a loader or an error?

Some Harley's Clan Forum pages are loaded dynamically from the HCF page service. A temporary connection, CDN, or page-service problem can show a loading or error screen. Retry the page first; if it continues, use Forum Support.

What should I do if the forum looks wrong on mobile?

Refresh the page, close and reopen the browser, and make sure browser zoom or forced desktop mode is not changing the layout. If the problem continues, report the device, browser, affected page, and a screenshot when possible.

Where are the forum rules?

Read the current community rules on the Forum Rules page before posting.

Where can I get help with my forum account?

Use Forum Support. Include your forum username, what you were trying to do, what happened, and any error message you saw. Never post your password or authentication codes publicly.

Forum App — Stable FAQ

AppStable

Stable channel: Intended for normal everyday use. Stable should follow Stable releases and should not install Beta / Development releases as normal updates.
What is the Stable app?

The Stable app is the regular Android release of Harley's Clan Forum. It opens the forum inside the HCF app interface and is intended to receive tested Stable updates.

Where should I download the Stable app?

Use the official Downloads page or another official Harley's Clan Forum download location. Avoid APK files reposted by unknown third parties.

How does the Stable updater decide whether an update is newer?

The app should compare the APK's numeric Android versionCode. The filename, GitHub tag, and display version name should not be the deciding factor.

Will Stable update to Beta / Development automatically?

No. Stable is a separate release channel and should remain on Stable releases unless you intentionally install a different app/channel.

Why does Android say "App not installed" or "App invalid"?

This can happen when the APK is damaged, built incorrectly, incompatible with the device, or signed with a different certificate than the installed copy. Android will not install an update over an existing app when the signing certificate does not match.

Why does Android ask me to allow installs from this source?

Android requires permission before an app such as your browser or the HCF app can hand an APK to the package installer. Only enable this for a source you trust, then continue the installation.

Can I keep my forum account when the app updates?

Normally yes. A regular in-place app update should preserve app data. Your actual forum account is stored by the forum service rather than being created by the APK itself.

Why are app notifications delayed or missing?

Check the app's notification permission, HCF notification settings, Android battery restrictions, background-data settings, and your forum notification preferences. Device power-saving modes can delay background activity.

What should I do if the app opens a blank or error page?

Check your internet connection, reopen the app, and try the forum again. If only one page fails, try opening another forum page. Use Forum Support if the problem continues.

Can the Stable app use a backup forum address?

The HCF app may support approved primary and backup forum domains. See Domain Help for official forum addresses.

Forum App — Beta / Development FAQ

AppBeta / Development

Testing channel: Beta / Development builds can contain newer changes that have not yet moved to Stable. Features, layouts, update behavior, and diagnostics may change more frequently.
What is the Beta / Development app?

It is the testing channel for newer HCF Android app changes before they are considered ready for the Stable channel.

Is Beta / Development the same as Stable?

No. They are separate channels. Beta / Development may contain features, interface changes, diagnostics, or update behavior that Stable does not have yet.

Should I use Beta / Development as my everyday version?

You can test it, but expect a higher chance of bugs or unfinished behavior. Use Stable when you prefer the regular release channel.

Where should I download Beta / Development builds?

Only use an official HCF testing download location or the official Downloads page when a testing build is offered there.

How are Beta / Development updates compared?

As with Stable, Android build ordering should use the APK's numeric versionCode. The display name or APK filename can describe the build, but should not replace versionCode comparison.

Can Beta / Development have features that Stable does not?

Yes. Testing builds are where newer app interface, update, notification, diagnostic, and other experimental changes may appear first.

Why did something change between two testing builds?

Beta / Development builds are expected to change more often. A feature may be adjusted, replaced, temporarily disabled, or reverted while it is being tested.

What should I include when reporting a Beta / Development bug?

Include the app channel, displayed version, numeric versionCode if available, Android version, device model, steps that reproduce the bug, what you expected, what happened instead, and a screenshot when useful.

Can I switch back to Stable?

Yes, but whether Android can install one over the other depends on package IDs, versionCodes, and signing certificates. If Android treats them as separate applications, both may coexist. If they use the same package ID, a downgrade or signature mismatch can block installation.

Where do I report testing-channel problems?

Use Forum Support and clearly say that you are using the Beta / Development app so the issue is not confused with Stable.
