I. Forum Basics

01What is Harley's Clan Forum?

Harley's Clan Forum is the community forum for discussions, announcements, messages, support information, downloads, and other Harley's Clan community pages.

02What is the official forum website?

The primary address is forum.harleytg.com. Bookmark the official address instead of relying on links from unknown messages or websites.

03Is there a backup forum address?

Yes. The FreeFlarum address is harleysclan.freeflarum.com. See Domain Help for the current official routing information.

04Do I need the Android app to use the forum?

No. The forum works as a website in a supported browser. The Android app is an additional way to access the same forum from a phone or tablet.

05Is the app a separate community from the website?

No. The app connects you to Harley's Clan Forum. Your forum discussions, account, messages, and other server-side forum content belong to the same forum service.

06Where are the important forum pages?

Use Forum Rules, Downloads, Support, and Domain Help. These pages are maintained as official HCF resources.

II. Accounts & Safety

07Do I use the same account on the website and app?

Yes. Sign in with the same Harley's Clan Forum account. You do not need a second account just because you switch between the website and the Android app.

08Are usernames and passwords case-sensitive?

Usernames are not case-sensitive. Passwords are case-sensitive. Enter your password using the same uppercase and lowercase letters you originally set.

09What should I do if I forget my password?

Use the forum's password-reset option from the sign-in screen. If you no longer have access to the email address on the account or the reset process fails, use Forum Support.

10What if my account is restricted, suspended, or I cannot sign in?

Check any message shown by the forum first. If you still need help, contact support and include your forum username, what you were trying to do, and the exact error message if one appears.

11What information should I never post publicly?

Do not publicly post passwords, password-reset links, authentication codes, private recovery information, payment details, or other sensitive personal information. Staff should not need your password to help with a normal support request.

III. Using the Website

12How do I start a discussion?

Sign in, choose the appropriate forum area or tags, and use the forum's discussion composer. Before posting, make sure the topic follows the Forum Rules.

13Does the forum support direct messages?

Yes, when messaging is available for your account. Use the forum's Direct Messages / Messenger interface for private conversations instead of posting private information in a public discussion.

14Where do forum notifications appear?

Forum notifications appear through the forum notification interface. Depending on your device and app/browser permissions, you may also receive supported system notifications.

15Why does the forum look different on mobile and desktop?

Harley's Clan Forum uses responsive layouts. Menus, buttons, notification controls, the composer, and other interface elements may move or collapse on smaller screens so the forum remains usable on phones and tablets.

16What should I do if an HCF page shows a loader or error code?

Retry the page once and confirm that you are online. If an HCF error reference such as a loader, route, network, or server code continues to appear, include that exact reference when contacting Support.

IV. Android App

17What does the Harley's Clan Forum Android app do?

The Android app provides a dedicated mobile interface for opening and using Harley's Clan Forum, with app-specific navigation, settings, update handling, notification support, and other Android-focused features.

18What Android versions are supported?

The current HCF Android app requires Android 8.0 (API 26) or newer. Some features, especially notification permissions and installer behavior, can differ by Android version and device manufacturer.

19Where should I download the app?

Use the official HCF Downloads page. Avoid APK files reposted by unknown third-party websites or sent from untrusted accounts.

20Why does Android ask me to allow installs from this source?

Android can require permission before an APK downloaded outside an app store can be installed. Only grant this permission to the trusted app you intentionally used to obtain the official HCF APK, and review the installer screen before continuing.

21Why does Android say “App not installed” or reject an update?

Common causes include a damaged download, insufficient storage, an incompatible Android version, or an APK signed with a different certificate than the version already installed. If the signing certificate does not match, Android will not treat the APK as a valid update to the installed app.

22Can Stable and Beta / Development be installed at the same time?

They can coexist when the builds use separate Android package IDs. If two APKs use the same package ID, Android treats them as versions of the same app instead of separate installs.

V. Stable vs Beta / Development

23What is the Stable app channel?

Stable is the normal release channel. It is intended for users who want the most tested HCF app build and should follow Stable releases rather than Beta / Development prereleases.

24What is the Beta / Development app channel?

Beta / Development is the testing channel for newer changes before they are promoted to Stable. It may update more often and can include features or fixes that are still being evaluated.

25Which app channel should I use?

Use Stable for everyday use. Choose Beta / Development if you intentionally want to test newer app changes and are comfortable reporting bugs or dealing with occasional unfinished behavior.

26How does the app decide whether an update is newer?

HCF app update checks use the APK's numeric Android versionCode to compare installed and available builds. The visible version name, release tag, or APK filename should not be used as the only indicator that a build is newer.

27What is the difference between version name and versionCode?

The version name is the human-readable version shown to users. The versionCode is Android's numeric build identifier. A newer release must use a higher versionCode for normal Android update logic.

VI. Notifications & Troubleshooting

28Why am I not receiving app notifications?

Confirm that forum notifications are enabled where applicable, then check Android's notification permission for the HCF app. Battery restrictions, background limits, Do Not Disturb, and manufacturer-specific power settings can also delay or block notifications.

29What should I try if the app cannot load the forum or I keep getting signed out?

Confirm your internet connection, retry the primary forum address, and check Domain Help if the custom domain is unavailable. If the website works in your browser but the app still fails, record the app version, Android version, and any error message before contacting support.

30How do I report a forum or app problem?

Open Forum Support. Include whether the problem is on the website, Stable app, or Beta / Development app; your app version/versionCode if relevant; your Android version; what you expected; what actually happened; and any HCF error reference shown on screen.
